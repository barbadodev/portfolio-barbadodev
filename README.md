# Portfolio Profesional — Antonio Barbado (@barbadodev)

Sitio web personal y portfolio de desarrollo full-stack. Diseñado para presentar proyectos reales a clientes y empresas, con arquitectura moderna basada en React, Vite y Tailwind CSS v4.

---

## 🚀 Proyectos Destacados Incluidos

1. **Calendario DAW:** Plataforma académica colaborativa con sincronización Moodle cada 15 min, PWA offline, Web Push y Supabase.
2. **Los Patios Restaurante:** Carta digital interactiva con filtros de alérgenos por normativa UE y reservas directas a WhatsApp.
3. **Dental Córdoba:** Web comercial de captación para negocios locales con detector de apertura en tiempo real y reseñas verificadas.

---

## 🛠️ Comandos de Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor local
npm run dev

# Compilar para producción (validación de 0 errores)
npm run build
```

---

## 🌐 Cómo desplegar tu Portfolio GRATIS en Vercel

1. Sube este proyecto a tu cuenta de GitHub como `portfolio-barbadodev` o `portfolio`.
2. En [vercel.com](https://vercel.com), pulsa **"Add New Project"** y selecciona este repositorio.
3. El preset **Vite** se seleccionará automáticamente. Haz clic en **Deploy**.
4. ¡Listo! Tendrás tu portfolio online en menos de 1 minuto con certificado SSL gratuito (ej. `antoniobarbado.vercel.app`).
